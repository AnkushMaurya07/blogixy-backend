# Accounts Module API

## Purpose
Authentication, user profile, user discovery, follow/friend flow, and messaging.

## Endpoints
- `POST /api/auth/register/`
- `POST /api/auth/login/`
- `POST /api/auth/token/refresh/`
- `GET/PATCH /api/auth/profile/`
- `GET /api/auth/users/`
- `GET /api/auth/follows/`
- `POST /api/auth/follows/create/`
- `GET/POST /api/auth/messages/`
